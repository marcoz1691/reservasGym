# Fotos de las áreas

Deja aquí las fotos reales de cada área del complejo. Aparecen solas en
«Próximas sesiones» y donde se use `AreaThumb`; no hay que tocar código.

## Nombre del archivo

El nombre debe coincidir con el `imageHint` de la zona (o con su tipo). Los que
usa el seed hoy:

| Archivo          | Área                  |
| ---------------- | --------------------- |
| `floor.jpg`      | Gimnasio              |
| `weights.jpg`    | Musculación           |
| `crossfit.jpg`   | CrossFit              |
| `hyrox.jpg`      | Hyrox                 |
| `dragon-fit.jpg` | Dragon Fit            |
| `dance.jpg`      | Bailoterapia          |
| `physio.jpg`     | Fisioterapia          |
| `nutrition.jpg`  | Nutrición             |
| `common.jpg`     | Áreas comunes         |

Extensiones aceptadas: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.

## Recomendaciones

- **Recorte cuadrado** (se muestran con `object-cover`, así que los bordes se
  recortan): compón el motivo al centro.
- **1000×1000 px** basta; por encima solo pesa más.
- Preferir `.webp` — pesa la mitad que un `.jpg` a la misma calidad.
- Sin texto ni logos quemados en la foto: encima van etiquetas de la interfaz.

Mientras no haya archivo, el área se dibuja con el tile duotono de marca y el
icono de su disciplina. Las fotos se pueden ir subiendo de a una.
